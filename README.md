# ソロ

沖縄で遊ばれてきたローカルなトランプゲーム「ソロ」を、スマホ1台を回して友人同士で遊べるWebアプリとして再現するプロジェクトです。

## ソロとは

トランプの1色2スート（A〜10の20枚）だけを使い、配られた2枚の役の強さを競うカブ系のゲーム。1970〜80年代の沖縄の学校で広く遊ばれていましたが、公式ルールが存在せず、記録もほとんど残っていません。

```
ソロ（同数2枚） ＞ 逆ソロ（9-6） ＞ ピン（A+10/9/5） ＞ 数字（合計の一の位）
特殊役：4-6（シロクの流れ）＝勝負を流す
```

最強の役は 10-10 の「バクダン」。

## 構成

```
packages/solo-engine   ルールエンジン（純粋TypeScript・依存ゼロ）
apps/web               Next.js アプリ
```

ルールエンジンを独立させているため、役判定と勝敗判定は UI から切り離してテストできます。

## 開発

```bash
npm install
npm run dev        # 開発サーバー
npm test           # エンジンのテスト（103件）
npm run typecheck
npm run build      # apps/web/out へ静的書き出し
```

## 技術構成

- Next.js (App Router) + TypeScript + Tailwind CSS
- バックエンドなし（完全クライアント完結・オフライン動作）
- 状態は `localStorage` にのみ保存し、外部へは送信しません

## 注意

本アプリのチップは仮想のポイントであり、現金・換金・課金の要素は一切ありません。
