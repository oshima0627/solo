# 沖縄のトランプゲーム「ソロ」調査記録

調査日: 2026-08-08

---

## 1. 概要

「ソロ」は沖縄県内でローカルに遊ばれてきたトランプゲーム。2〜6人用で、1ゲーム数十秒〜3分程度で決着する、役の強弱を競うカブ系（おいちょかぶ系）の賭博ゲーム。

- 1970年代後半〜1980年代の沖縄の中学・高校で非常にポピュラーだった。放課後や休み時間に「シッピン」「クッピン」の声が飛んでいたという証言が複数あり、他校でも遊ばれていた＝県内全域に広まっていたとみられる
- 勝負が早いため、少額を賭けて遊ばれるのが常だった
- **公式ルールが存在せず、ローカルルールの分岐が非常に多い**。まとまった解説はブログ記事1本とそのコメント欄が事実上の一次資料になっている

## 2. 基本ルール

### 使用道具

- トランプの**1色2スート（例：♠＋♣）のA〜10＝計20枚**
- J・Q・K・JOKER・もう1色は使わない → カブ札（20枚構成）の代用であることが明白

### 流れ

1. 20枚をシャッフル
2. 各人に3枚配る（※2枚配りで即勝負のバリアントもある）
3. 各自1枚捨てる
4. 一斉に手札2枚を公開し、役の強さを比べる
5. 最強の人がチップを総取り

**親・子の概念が無く全員イーブン**。これがおいちょかぶとの最大の相違点。

## 3. 役一覧（強い順）

| 区分 | 役 | 内容 | 別名 |
|---|---|---|---|
| ソロ | 10ソロ | 10・10 | **爆弾（バクダン）** |
| ソロ | 9ソロ | 9・9 | |
| ソロ | 8〜2ソロ | 同数2枚 | |
| ソロ | 1ソロ | A・A | **ピンゾロ** |
| 逆ソロ | 逆ソロ | 9・6 | |
| ピン | 10ピン | A・10 | テンピン |
| ピン | 9ピン | A・9 | **クッピン** |
| ピン | 5ピン | A・5 | ゴピン |
| 数字 | 9（カブ）〜1、0 | 2枚の合計の一の位 | 0は「ブタ」 |
| 特殊 | 46 | 4・6 | **シロクの流れ**＝その勝負を無効化・流す |

要約すると **ソロ ＞ 逆ソロ ＞ ピン ＞ 数字**。

補足:

- A・8は合計9なので「カブ」扱い（ピンにはならない）
- 4・6は合計10＝本来ブタなのに、特別に「流れ」になる
- ピンは10・9・5の3種のみが多数派。ただし証言に「シッピン（4・1）」も登場しており、おいちょかぶ（シッピン＝4-1、クッピン＝9-1、ゴッピン＝5-1）の役名がそのまま流入している
- **ピン役は「本来弱い手の救済」として機能している**（A-9は合計0＝ブタなのにクッピンで強い、A-10も合計1なのにテンピン）。逆にA-8は合計9＝カブなので救済不要でピンにならない

### 資料が割れている点

**ピンゾロ（A・A）の強さ**について証言が分かれる。

- 「爆弾の次に強い」とする証言（まちBBS 161）
- 「ソロの中で最弱（10ソロ→…→1ソロの順）」とする記述（まちBBS 162、孤独のボドゲ、ソッタ解説サイト）

後者が多数派かつ体系的。

## 4. 賭け方（2系統）

### A. 定額アンティ方式

1. 配る前に全員チップ1枚を場に出す
2. 手札を見て「勝負／降り」を決め、「せーの」で一斉に意思表示（勝負＝捨て札1枚を出す／降り＝手札3枚全部を出す）
3. 勝負する人は公開時に追加チップ1枚。ただし**46の人は追加免除**
4. **爆弾（10ソロ）が出たら、残っている全員が追加で3枚支払う**（46の人は免除）
5. 最強役が総取り。同点・46出現・全員降りは**引き分け＝場のチップは次ゲームへ持ち越し**

爆弾ボーナスは「4倍付け」「掛け金＋100」など地域差あり。

### B. ポーカー型レイズ方式

- 配るのは**2枚のみ・交換なし**、役は「ソロ10種＋ピン3種（10/9/5）＋通常のカブ役」だけとシンプル
- 前回の勝者から順に降りるかレイズかを判断、**レイズ上限なし**
- **降りるときもカードは公開しない**
- 爆弾で勝ったら場のチップ＋各人10枚（降りた人も支払う）
- 「レイズで周りを降ろしてブタで勝つ」のが醍醐味

Bのほうが韓国の「ソッタ」（ポーカー式ベッティング）に構造が近い。

## 5. 主なローカルルール

- **並び役（スカーレット）**: 南風原では3枚の連番役があり、8-9-10が最強、1-2-3でも爆弾より強い。3枚配りのまま勝負する変種
- **5-6-7を貰ったら3枚捨てて引き直し**
- **2枚配り**（運要素が増す。あまり人気は無かったとの証言）
- **逆ソロ・シロクは「学生が作ったルールでは」**という説
- 役の呼称・採用役はグループ単位で分岐

## 6. 起源・系譜

ソロは東アジアに広がる「カブ系賭博」の沖縄ローカル変種と位置づけられる。

- **おいちょかぶ置換説**: シッピン・クッピン・アラシといった役名がおいちょかぶと共通。花札・株札は賭博道具として学校で敵視されたため、トランプに置き換えて遊ばれたというストーリー。ただし配り方が違い、単純な置換ではない
- **中国由来／韓国ソッタ同系説**: 韓国の花札ゲーム「ソッタ」（20枚使用・2枚配り・ポーカー式ベッティング・特殊役多数）はソロと構造がほぼ同じ。ソッタ自体は花札流入以前の朝鮮の紙牌「闘牋（トゥジョン）」の遊びとおいちょかぶ系ルールの融合とされる。「沖縄のソロは中国からもたらされた」との説もあるが、名称の類似（ソロ／ソッタ）を含め決定的な証拠は無い
- **国内の同系ゲーム**: 兵庫の「かちかち」（株札・2枚配り・一の位勝負・シッピン/ゴッピン・4-6シロクは逃げ・10-10がジュンジュン＝カチカチで最強）はソロとほぼ同一構造。関東の「ケンペイ」、関西の「セッタ」、「ドンドン」も同系
